# 출시 실무 자료는 이 repo 밖에 있다

출시 지그·씨딩 초안·채널 전략은 **공개 repo에 노출되면 곤란한 자료**라 2026-07-26에 로컬 `~/Downloads/devetym-release/`로 옮겼다. 이 파일은 그 사실을 알리는 포인터이며, 여기서 링크로 이어지는 실물은 없다.

- **상태 정본은 [`ROADMAP.md`](../../ROADMAP.md)** — 출시 일정·잔여 결정은 전부 거기 있다.
- **git 밖이다.** 이관 후 생성분은 git 이력에 없다 → 삭제 시 복구 경로는 스냅샷뿐이다: **`~/Downloads/devetym-release-snapshot-2026-08-25.tar.gz`**.
- 이관 전 원본은 repo 이력에 있다: `git show b4d6b3e^:docs/release/<옛이름>` (`git log -- docs/release/`로 목록 확인).
