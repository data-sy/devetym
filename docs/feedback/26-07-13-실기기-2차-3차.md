# 26-07-13 · 실기기 피드백 2차·3차

> **채널** 아이폰 13 mini 실기기 직접 사용 · **대상** iOS 앱 M9 빌드 · **회차** 같은 날 2차(3건)→3차(6건) 연속 접수
> **이관 기록**: 이 창구가 생기기 전 접수분이라 `docs/specs/m9-ux-shell-redesign-draft.md` §0·ROADMAP에서 원문을 옮겨 왔다(2026-08-07).

## 2차 (3건)

| # | 증상 (받은 그대로) |
|---|---|
| UX-4 | 복사 버튼이 "왜 이 이름인가" 밑에 있는데 어원만 복사된다 — 뭐가 복사되는지 오인함 |
| UX-5 | 뒤로가기가 전환 애니메이션 없이 휙 바뀐다 |
| UX-6 | 공유 버튼을 눌러도 아무 반응이 없다 |

## 3차 (6건)

| # | 증상 (받은 그대로) |
|---|---|
| 3-1 | 키보드가 뜨면 화면 전체가 올라가 헤더·최근 검색이 사라진다 |
| 3-2 | 키보드를 한 번 열면 끌 방법이 없다 |
| 3-3 | 탭을 스와이프해 넘겨도 키보드가 열린 채로 있다 |
| 3-4 | 하단 바에 리퀴드 글라스를 적용하면 좋겠다 (제안) |
| 3-5 | 설정의 문의·앱 평가·오류 제보·개인정보 처리방침이 전부 안 뜬다 + 상세의 공유도 마찬가지 |
| 3-6 | 엣지 스와이프-백이 상세에서만 된다. 라이선스 화면은 back 버튼이 스크롤 내용물 안에 있어 스크롤하면 사라지고, 노치에 깔려 탭이 안 된다 |

## 사용자 지시

> **"땜질 금지 · 클린 설계 후 스텝 구현"**

증상별 화면 국소 패치를 금지하고 셸 계층(네비·인셋·키보드·플랫폼 액션)을 정본화하는 방향으로 받았다.

## 처리

- **설계 정본**: [`../specs/m9-ux-shell-redesign-draft.md`](../specs/m9-ux-shell-redesign-draft.md) — 접수 당일 승인, 스텝 1~3 분할 구현
- **결과**: 3-4를 제외한 전건 종결 (2026-07-13 하루에 접수→설계 승인→구현→실기기 배포→라운드 2→사인오프). 세부는 ROADMAP 해당 항목
- **미종결**: 3-4 하단 바 리퀴드 글라스 — 출시 전 검토 백로그, 미확정

## 참고 — 1차 피드백

같은 날 오전 접수된 1차분은 **원문 기록이 남아 있지 않고** 대응 내역만 ROADMAP("실기기 1차 피드백(라운드 2) 반영·재배포")에 있다: 공유 시트 프레젠테이션, 공유 내용 전문화, 앱 평가 iOS 26 대응, 전환 속도, 키보드 dismiss 경합, 자동완성 UX 6건. 이 창구를 만든 이유가 이것 — 대응만 남고 원문이 증발하면 나중에 판단 근거를 못 되짚는다.
