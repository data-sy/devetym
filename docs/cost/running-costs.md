> **이 문서의 성격**: 결정 문서가 아니라 **원장**이다. "얼마를 어디에, 언제 또 내는가"만 적는다.

## 6. 도메인 — 「네임서버 위임」과 「등록기관 이전」은 다른 일이다

혼동하기 쉬워 못 박아 둔다. **W0b가 하는 것은 앞의 것뿐이다.**

| | 네임서버 위임 (W0b가 하는 것) | 등록기관 이전 (지금 안 한다) |
|---|---|---|
| 바뀌는 것 | `devetym.com`의 DNS 질의에 **누가 응답하는가** | 도메인의 **등록·결제·소유 관리 주체** |
| 소유자 | 그대로 (Amazon Registrar 등록) | Amazon → Cloudflare |
| $16/yr 청구 | **그대로 Amazon** | Cloudflare (원가 판매, .com 약 $10/yr) |
| 자동 갱신 설정 | **영향 없음** | 새로 설정 필요 |
| 되돌리기 | Amazon 콘솔에서 NS 원복 — 즉시 | 60일 잠금·인증 코드 필요 |

**왜 위임이 필요한가**: Worker 커스텀 도메인은 해당 존이 Cloudflare에 있어야 붙는다([ADR-0009](../adr/0009-web-framework-rendering.md) D4가 Cloudflare를 고른 결과). 게다가 apex 도메인(`devetym.com`)은 표준 DNS에서 CNAME을 걸 수 없어 외부 DNS로 우회할 방법도 없다.

**지금이 가장 싼 시점**: 도메인에 아직 아무 레코드도 없다(신규 등록). 옮길 것도, 끊길 것도 없다.

**부수 이득**: Route 53 호스팅 영역이 불필요해져 **$0.50/월을 안 낸다**(§4). Cloudflare DNS는 무료.

**등록기관 이전은 지금 불가능하다** — ICANN 규칙상 신규 등록 후 **60일간 잠긴다**(→ 2026-10-24 이후 가능). 그때 옮기면 연 $5 안팎이 절약되나 급하지 않다. 판단은 그때.

## 7. Route 53 호스팅 영역 — 왜 $0 로 끝났나 (2026-08-25)

**하나 알아 둘 것: 도메인 등록과 DNS 호스팅은 AWS에서 별도 과금이다.**

- **등록된 도메인**(Registered domains) = 소유권. $16/yr. **건드리면 안 되는 쪽.**
- **호스팅 영역**(Hosted zones) = DNS 응답 서비스. **영역당 $0.50/월**, 도메인을 사면 대개 자동으로 하나 생긴다.

DNS를 Cloudflare로 위임했으므로 Route 53 호스팅 영역은 **아무도 조회하지 않는 빈 껍데기**가 됐다 — 놔두면 매달 $0.50이 아무 일도 안 하고 나간다.

**"12시간 안이면 요금이 안 붙는다"의 의미**: AWS는 **생성 후 12시간 이내에 삭제된 호스팅 영역에는 과금하지 않는다**(공식 정책). 12시간을 넘기면 그 달치 $0.50이 일할 계산 없이 붙는다. 도메인 등록이 04:29 UTC였고 그날 안에 삭제했으므로 **청구액 0**이다.

> 즉 "무료 체험"이 아니라 **"만들자마자 지운 건 안 받는다"** 는 규정이다. 뒤늦게 발견해 지우면 이미 붙은 달치는 사라지지 않는다 — 그래서 **지금** 하는 게 맞았다.

⚠️ **삭제한 것은 호스팅 영역이지 도메인이 아니다.** Registered domains의 `devetym.com`은 그대로이며 자동 갱신도 켜져 있다.

## 갱신 규칙

- 새 비용이 생기면 **그날** 여기에 적는다. 금액·주기·다음 갱신일·**끊기면 무슨 일이 나는가**를 반드시 채운다.
- 무료 티어에 새로 얹으면 §2에 적는다. "무료라서 안 적었다"가 나중에 청구서로 돌아온다.
- 실측이 나오면 §3에 넣는다. **추정치는 여기 넣지 않는다** — 추정은 결정 문서의 몫이다.
- 갱신일이 지나면 다음 갱신일로 갱신한다. 캘린더 리마인더는 사람이 별도 등록한다(Admin 키 회전 선례 — ROADMAP `Later` `[Ops]`).
